1. Tokens & Embeddings — From Text to Vectors

Language models do not directly process words as humans see them. Text is tokenized into integer IDs, then mapped to vectors that a neural network can transform.

1. Tokenization

A tokenizer splits text into units from a finite vocabulary. A token may be a whole word, a word fragment, punctuation, or a whitespace-associated unit. The exact split depends on the tokenizer.

text = "unbelievable!"
# Illustrative only; actual token IDs depend on the tokenizer:
tokens = ["un", "believ", "able", "!"]
token_ids = [41, 812, 207, 9]

Token IDs are category labels, not numerical meanings: ID 812 is not “twice” ID 406. A vocabulary maps token strings to IDs, often using tables or specialized tokenization algorithms.

2. Embedding lookup

An embedding table is a matrix with one learned vector per token ID. Looking up an ID selects a row. The vector dimension is a model design choice, and its coordinates are learned jointly with the rest of the model.

# Conceptual shape:
# token_ids: [batch, sequence_length]
# embedding_table: [vocabulary_size, hidden_size]
# embedded: [batch, sequence_length, hidden_size]
embedded = embedding_table[token_ids]

3. Position and context

Token embeddings alone do not encode sequence order. Transformer models add positional information or otherwise encode position so the model can distinguish “dog bites person” from “person bites dog”. Contextual representations then change as tokens interact through layers.

4. Tokens are not characters

  • One word can be split into multiple tokens.
  • Different languages can have different token efficiency.
  • Spaces, punctuation, and formatting can affect tokenization.
  • Context windows are measured in tokens, not simply words or characters.

5. Why it matters in practice

Token count affects prompt limits, latency, and usage cost. When building retrieval systems, chunk by token budget as well as semantic boundaries. For multilingual content, test the actual tokenizer rather than estimating from character count.

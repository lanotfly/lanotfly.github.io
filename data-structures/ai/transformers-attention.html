2. Transformers & Attention — How Context Is Mixed

A Transformer repeatedly transforms token vectors. Self-attention lets each position combine information from other positions, while feed-forward layers transform each position's representation.

1. Query, key, and value

Each input vector is projected into a query (Q), key (K), and value (V). Similarity between a query and keys produces attention scores; softmax converts scores into weights; the weighted sum of values becomes the attended representation.

The scaled dot-product attention operation is commonly written:

Attention(Q,K,V) = softmax(QKᵀ / √dₖ) V

The scale factor helps keep dot-product magnitudes manageable as the key dimension grows. Implementations use optimized matrix multiplication and may avoid materializing the full score matrix.

2. Multi-head attention

Multiple heads learn different projections and can capture different relationships. Their outputs are concatenated and projected. In decoder-only language models, a causal mask prevents a token from attending to future tokens during next-token prediction.

3. Transformer block

  1. Normalize input representations.
  2. Apply attention to exchange information across positions.
  3. Add a residual connection.
  4. Apply a feed-forward network independently at each position.
  5. Add another residual connection and normalization according to the architecture.

4. Next-token prediction

The model produces scores (logits) over the vocabulary. Softmax turns them into a probability distribution. A decoding strategy—greedy, temperature sampling, top-k, or nucleus sampling—selects the next token. The process repeats until a stop condition or output limit is reached.

5. Complexity intuition

Full self-attention across a sequence of length n typically has O(n²) pairwise interaction cost and memory pressure for the attention scores. Long-context systems use optimized kernels, cache key/value states during generation, or other architecture-specific techniques.

6. Common misconceptions

  • Attention weights are not a complete explanation of a model's reasoning.
  • One attention head does not necessarily correspond to one human-readable concept.
  • A fluent prediction is not a guarantee of factual accuracy.

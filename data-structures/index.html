Where data structures appear in real systems

Arrays & strings

Contiguous storage gives fast indexed access. Used for image pixels, time-series samples, buffers, text processing, and cache-friendly numeric workloads.

Hash tables & sets

Fast average-case key lookup and membership checks. Used in caches, symbol tables, deduplication, counting, session stores, and indexes in application code.

Linked lists

Efficient local insertion/removal when a node is already known. Useful for teaching pointer mechanics and in some intrusive lists, though arrays/deques are often better in everyday application code.

Stacks & queues

Stacks power call frames, undo/redo, parsing, and backtracking. Queues power task pipelines, event handling, breadth-first search, and producer-consumer systems.

Trees & heaps

Trees model hierarchy, ordered indexes, syntax, and prefixes. Heaps prioritize the next task or event in schedulers, pathfinding, and top-K queries.

Graphs

Represent relationships: social networks, road maps, dependencies, network topology, package managers, and recommendation systems. BFS/DFS and shortest-path algorithms operate on them.

Tries

Prefix-aware lookup for autocomplete, dictionaries, spell-checking, IP routing prefixes, and searching many words that share prefixes.

Union-Find

Tracks connected groups as relationships are added. Used for connectivity, cycle detection in undirected graphs, clustering, and Kruskal's minimum spanning tree algorithm.

🗺️ A 4-Week Interview Plan

  • Week 1: Arrays, Hash Tables, Sorting & Binary Search — these appear in ~60% of screens.
  • Week 2: Linked Lists, Stacks & Queues, Trees.
  • Week 3: Heaps, Graphs, Tries, Union-Find.
  • Week 4: Mixed timed practice. For every problem: brute force first,

name the bottleneck, pick the structure that removes it, then code.

3. Vector Search & RAG — Retrieve Evidence Before Generation

Retrieval-augmented generation (RAG) combines search over external data with a language model. It is useful when answers must draw on documents that may be private, changing, or too large to fit in a prompt.

1. Embeddings and similarity

An embedding model maps text or other content to a vector. Similarity measures such as cosine similarity or dot product rank candidates, but “similar” depends on the embedding model and the task.

import numpy as np

def cosine_similarity(a, b):
    a, b = np.asarray(a), np.asarray(b)
    denom = np.linalg.norm(a) * np.linalg.norm(b)
    return 0.0 if denom == 0 else float(a @ b / denom)

2. Indexing pipeline

  1. Collect and normalize source documents.
  2. Split documents into chunks with useful overlap and metadata.
  3. Calculate an embedding for each chunk.
  4. Store vectors alongside text, source ID, timestamp, and access metadata.
  5. Build an exact or approximate nearest-neighbour index.

3. Query-time pipeline

  1. Embed the user's query.
  2. Retrieve top candidates using vector, keyword, or hybrid search.
  3. Apply permission and metadata filters.
  4. Optionally rerank candidates with a stronger relevance model.
  5. Fit selected evidence within the context budget and ask the model to answer from it.
  6. Return citations or source references and evaluate whether the answer is supported.

4. Exact vs approximate search

Exact nearest-neighbour search compares the query with every vector and can be expensive at scale. Approximate nearest-neighbour (ANN) indexes trade a controlled amount of recall for lower latency. HNSW and IVF-style indexes are common design families; their trade-offs depend on data size and tuning.

5. Failure modes

  • Chunking separates a fact from its heading or necessary context.
  • Embeddings retrieve semantically similar but incorrect passages.
  • Stale documents or wrong permissions leak into the context.
  • The context contains evidence but the generated answer ignores it.
  • Prompt injection inside retrieved content attempts to influence tool use.

6. Evaluate components separately

Measure retrieval recall and relevance separately from answer correctness and groundedness. Include “no answer in corpus” cases, access-control tests, and freshness tests. RAG can improve grounding, but it does not guarantee correctness.

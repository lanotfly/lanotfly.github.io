Linux filesystem structure

Linux uses one directory tree that begins at / (the root directory). These locations are common on Linux distributions, though exact contents and conventions can vary.

Directories you should recognize

PathWhat it containsWhen you use it
/The root of the entire directory tree.Starting point for absolute paths.
/homeRegular users' home directories, such as /home/alex.User files and personal configuration.
/rootThe root administrator's home directory.Administrative files; usually requires elevated privileges.
/etcSystem-wide configuration files.Inspect service and host configuration.
/varVariable data such as logs, caches, spools, and application state.Investigate logs and growing data.
/usrMany user-space programs, libraries, and shared read-only data.Find installed commands and libraries.
/bin, /sbin, /libEssential commands and libraries; on many modern distributions these are symlinks into /usr.Understand compatibility paths.
/optOptional/add-on application software.Locate software installed outside the package manager's usual layout.
/tmpTemporary files, often cleaned automatically.Short-lived scratch files; do not assume data persists.
/devDevice nodes representing devices and kernel interfaces.Understand devices such as disks and terminals.
/procVirtual files exposing process and kernel information.Inspect process IDs and kernel settings.
/sysVirtual view of devices and kernel objects.Inspect hardware and driver-related information.
/runRuntime state created since boot, such as PID files and sockets.Inspect service runtime information.
/bootBootloader and kernel-related files on many systems.Troubleshoot boot configuration carefully.
/mnt, /mediaCommon mount points for manually mounted filesystems and removable media.Find mounted disks or external media.

Absolute vs relative paths

# Absolute path: starts at /
cd /var/log

# Relative path: starts from the current directory
cd ..
cd ./nginx

# Useful path shortcuts
cd ~
cd -
pwd
  • . means the current directory; .. means its parent.
  • ~ expands to your home directory in most shells.
  • Use findmnt or df -h to understand mounted filesystems and space usage.

Inspect the filesystem safely

ls -lah /
find /etc -maxdepth 2 -type f
df -h
findmnt
du -sh /var/log

SRE tip: when a disk is full, check both filesystem capacity (df -h) and directory usage (du -xhd1 /var, where supported). A large directory and a full filesystem are related but not identical clues.

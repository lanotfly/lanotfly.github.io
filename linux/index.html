A simple mental model

  • Everything starts at /: Linux organizes files and directories in one directory tree, even when storage devices are mounted underneath it.
  • Commands operate on paths and processes: learn the current directory, absolute versus relative paths, standard input/output, and exit status.
  • Inspect before changing: use read-only commands first; understand a command's target and options before deleting files or changing permissions.

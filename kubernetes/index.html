Kubernetes — From Pods to Production

A visual, practical guide to the Kubernetes objects and operating practices used to run containerized applications. Start with Pods, then follow how workloads are deployed, exposed, configured, monitored, and secured.

Chapters

Pods

A Pod wraps one or more tightly coupled containers and gives them a shared network identity and storage context.

Learning path

  1. Understand Pods and how Deployments keep the desired number of replicas running.
  2. Expose workloads with Services and configure them safely with ConfigMaps and Secrets.
  3. Plan storage, health probes, resource requests, and autoscaling.
  4. Apply least-privilege access, workload hardening, network controls, and a repeatable troubleshooting process.

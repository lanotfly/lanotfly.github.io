3. Recursion & Backtracking — State, Choices, Undo

Recursion expresses a problem in terms of smaller versions of itself. Backtracking explores a decision tree and undoes each choice when returning from a branch.

1. The recursion contract

Before writing recursive code, identify four things: the function's meaning, the base case, how the input gets smaller, and how sub-results are combined. The call stack uses O(depth) memory.

def factorial(n: int) -> int:
    if n <= 1:
        return 1
    return n * factorial(n - 1)

2. Backtracking template

Backtracking has a state, a set of choices, a stopping condition, and an undo step. It is common for subsets, permutations, combinations, and grid paths.

def subsets(nums):
    result, path = [], []
    def visit(i):
        if i == len(nums):
            result.append(path.copy())
            return
        visit(i + 1)                 # exclude nums[i]
        path.append(nums[i])         # choose
        visit(i + 1)                 # explore
        path.pop()                   # undo
    visit(0)
    return result

There are 2^n subsets, so output itself is exponential. Copy the mutable path when saving an answer; otherwise every result can point to the same list.

3. Pruning

Pruning stops exploring a branch once it cannot produce a valid answer. For Combination Sum, if candidates are sorted and the current candidate exceeds the remaining target, later candidates can be skipped too. Good pruning can greatly reduce real work, but the worst case may remain exponential.

4. Divide and conquer vs. backtracking

TechniquePurposeExample
RecursionDescribe smaller subproblemsTree traversal, factorial
Divide and conquerSolve independent pieces and combineMerge sort
BacktrackingEnumerate choices with undo and pruningPermutations, N-Queens
Dynamic programmingReuse overlapping subproblem resultsCoin Change

5. Graph Algorithms — Topological Sort, Union-Find & Shortest Paths

Model entities as vertices and relationships as edges. Choose the algorithm according to the question: dependency order, connectivity, or shortest path.

1. Graph representations

An adjacency list stores each vertex's neighbours and uses O(V+E) memory. An adjacency matrix uses O(V²) memory but makes edge-existence checks O(1). Sparse graphs usually favour adjacency lists.

2. Topological sort

For a directed acyclic graph (DAG), topological ordering places every prerequisite before its dependent task. Kahn's algorithm repeatedly removes vertices with indegree zero.

from collections import deque

def topo_sort(graph, indegree):
    indegree = indegree.copy()
    q = deque(v for v, d in indegree.items() if d == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                q.append(v)
    return order if len(order) == len(indegree) else []

If fewer than V nodes are emitted, the graph contains a directed cycle. Complexity: O(V+E).

3. Union-Find / Disjoint Set Union

Union-Find maintains connected components as edges are added. Path compression and union by size/rank make operations nearly constant amortized time, O(α(n)). It is excellent for connectivity but does not directly support arbitrary edge deletions.

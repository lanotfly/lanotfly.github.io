1. Array Patterns — Two Pointers, Sliding Window & Prefix Sum

Array and string problems become easier when you recognize the invariant: what the pointers mean, which elements belong to the current window, or what a prefix total represents.

1. Two pointers

Use two indices when order or the two ends of a sequence provide useful information. For a sorted pair-sum problem, moving the left pointer right increases the sum; moving the right pointer left decreases it.

def two_sum_sorted(nums: list[int], target: int) -> list[int]:
    left, right = 0, len(nums) - 1
    while left < right:
        total = nums[left] + nums[right]
        if total == target:
            return [left, right]
        if total < target:
            left += 1
        else:
            right -= 1
    return []

Complexity: O(n) time and O(1) extra space. Correctness depends on sorted order. On an unsorted array, use a hash map or sort a copy if index requirements allow it.

2. Sliding window

A sliding window represents a contiguous range [left, right]. Expand right to include new data, then move left until the invariant becomes true again. Each pointer moves at most n times, so many window algorithms are O(n).

def longest_unique_substring(s: str) -> int:
    last_seen = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best

This pattern fits contiguous substrings and subarrays—not arbitrary subsets. Before coding, state exactly what makes the window valid.

3. Prefix sums

Define prefix[i] as the sum of elements before index i. Then the sum of the half-open range [l, r) is prefix[r] - prefix[l]. Precomputation costs O(n); each range query is O(1).

def range_sums(nums):
    prefix = [0]
    for x in nums:
        prefix.append(prefix[-1] + x)
    return lambda left, right: prefix[right] - prefix[left]

For “subarray sum equals k”, store how often each prefix sum has appeared. At current sum s, each earlier prefix equal to s-k identifies a valid subarray.

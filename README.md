# Data Structures Wiki — for Coding Interviews

A wiki-style book of the data structures that matter in coding interviews,
built as HTML pages with a diagram for every structure and clean Python
examples for every chapter. Read it online:

**📖 https://lanotfly.github.io/data-structures/**

## Chapters

1. [Arrays & Strings](data-structures/array-string.html) — two pointers, sliding window
2. [Hash Table — dict & set](data-structures/hash-table.html) — counting, Two Sum, grouping
3. [Linked List](data-structures/linked-list.html) — reversal, dummy head, Floyd's cycle detection
4. [Stack & Queue](data-structures/stack-queue.html) — parentheses, monotonic stack, deque
5. [Tree & Binary Search Tree](data-structures/tree-bst.html) — traversals, LCA, validation
6. [Heap / Priority Queue](data-structures/heap.html) — top-K, merge K, streaming median
7. [Graph](data-structures/graph.html) — BFS/DFS, islands, topological sort, Dijkstra
8. [Trie (Prefix Tree)](data-structures/trie.html) — prefix search, autocomplete
9. [Union-Find (Disjoint Set)](data-structures/union-find.html) — connectivity, provinces
10. [Sorting & Binary Search](data-structures/sorting-binary-search.html) — merge sort, search on the answer

Each chapter: a picture of the structure, when to use it, a complexity
cheat sheet, a core Python implementation, a classic interview problem
solved end to end, pitfalls, and practice problems.

## About this site

This repository is a Jekyll site (GitHub Pages). The wiki book lives in
[`data-structures/`](data-structures/) as HTML pages with a shared
stylesheet (`wiki.css`). The theme scaffolding (`_layouts/`, `_includes/`,
`_sass/`, `css/`) is kept so the site renders.

Welcome to star ⭐ if it helps your interview prep.

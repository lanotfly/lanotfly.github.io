# Data Structures Wiki — for Coding Interviews

A wiki-style book of the data structures that matter in coding interviews,
with clean Python examples for every chapter. Read it online:

**📖 https://lanotfly.github.io/data-structures/**

## Chapters

1. [Arrays & Strings](data-structures/array-string.md) — two pointers, sliding window
2. [Hash Table — dict & set](data-structures/hash-table.md) — counting, Two Sum, grouping
3. [Linked List](data-structures/linked-list.md) — reversal, dummy head, Floyd's cycle detection
4. [Stack & Queue](data-structures/stack-queue.md) — parentheses, monotonic stack, deque
5. [Tree & Binary Search Tree](data-structures/tree-bst.md) — traversals, LCA, validation
6. [Heap / Priority Queue](data-structures/heap.md) — top-K, merge K, streaming median
7. [Graph](data-structures/graph.md) — BFS/DFS, islands, topological sort, Dijkstra
8. [Trie (Prefix Tree)](data-structures/trie.md) — prefix search, autocomplete
9. [Union-Find (Disjoint Set)](data-structures/union-find.md) — connectivity, provinces
10. [Sorting & Binary Search](data-structures/sorting-binary-search.md) — merge sort, search on the answer

Each chapter: when to use it, a complexity cheat sheet, a core Python
implementation, a classic interview problem solved end to end, pitfalls,
and practice problems.
